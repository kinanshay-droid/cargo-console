# AFIK Logistics Platform

A logistics operations console for managing shipments, leads, quotes, customers,
and organization settings.

## Development

You need Node.js and npm.

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```

## Built with

- TanStack Start
- TypeScript
- React
- Tailwind CSS
- Supabase
